# Условный выбор ресурсов

Контроллер выбирает документ по этапу или симптому из таблицы SKILL.md.
Роль получает точный бриф, применимые правила и свой шаблон; общие разрешения остаются в SKILL.md.
`project-documentation.md` вызывается при каждом старте и сохранении результата.
Остальные справки читаются для назначенной задачи. Планирование не расширяет право на коммит или публикацию.

## Помощники

`sdd-workspace.mjs` изолирует план и проверяет идентичность журнала.
`task-brief.mjs` извлекает одну задачу без изменения результата при ошибке извлечения.
`review-package.mjs` собирает коммиты либо перечисленные пути рабочего дерева без изменения индекса и HEAD.
Новые, удалённые и бинарные файлы входят в пакет; чужие изменения общего файла требуют явного разграничения.
Node.js и Git CLI выполняют эти операции, снимки файлов заменяют Git-пакет при отсутствии Git/BASE.

## Доказательства

Результаты проверок относятся к фактическим файлам и окружению. Новая проверка нужна после
затрагивающего изменения или конкретного сомнения. Независимое ревью называется независимым
только при отдельном проверяющем. Непроверенные обязательные пункты и ограничения сохраняются.
