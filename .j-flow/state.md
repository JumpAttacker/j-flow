# Состояние j-flow

Обновлено: 2026-10-05

## Цель

Переносимый полный цикл разработки для Codex, Claude Code и ZCode с постоянными документами каждого проекта.

## Описание проекта

Назначение и устройство: [project.md](project.md). Повторяемые проверки: [checks.md](checks.md).
Функции и принятые процессы: [features/README.md](features/README.md).

## Текущая работа

- Постоянный комплект: описание/архитектура, state, индекс функций и подтверждённые проверки.
- Каждый старт дополняет недостающее, каждый хвост актуализирует результат и открытые вопросы, включая FAIL/BLOCKED.
- Новые пустые проекты и старые частичные установки проходят тот же маршрут с честным статусом реализации.
- 16 собственных условных справок покрывают решение, план, исполнение, ревью, проверки и документацию.
- Утилиты заново реализованы на Node.js по функциональным контрактам; требуется Node и Git CLI для Git-режима.
- Без Git/BASE сохраняются журнал и снимки файлов, технический коммит ради процесса не создаётся.
- Обслуживание документов проверено агентами на пустом, существующем и изменённом проекте с незавершённой приёмкой.
- В плане используются проверяемые части результата с зависимостями, в карте описаны понятия и контракты модулей.

## Ограничения проверок

- Проверки инструкций и установок не означают полный живой цикл разработки в каждом клиенте.
- Исполнение утилит проверено на Windows; отдельный Linux-прогон не выполнялся.
- Внешние инструменты и специализированные процессы определяются правилами проекта и назначенной работой.
