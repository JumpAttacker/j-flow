# Состояние j-flow

Обновлено: 2026-10-05

## Цель

Самодостаточное распространение через GitHub и `npx skills` для ZCode, Claude Code и Codex.

## Структура ресурсов

- Справки и шаблоны ролей: `references/` (15 Markdown-документов).
- Исполняемые помощники: `scripts/sdd-workspace`, `task-brief`, `review-package`.
- Полный исходный MIT notice сохранён в `THIRD_PARTY_NOTICES.md`; лицензия j-flow в `LICENSE`.
- Ссылки контроллера, ролей, стартового хука и тестов используют новую структуру.
- Материалы являются адаптацией; смена имени папки не меняет их происхождение.

## Текущая редакция документов

- Пользователь одобрил сокращение и исправление противоречий после аудита.
- Общие правила и условия загрузки перенесены в SKILL.md; шаблоны ревью сохранили
  отдельные области проверки. Набор справок и помощников сокращён с 3392 до 1000 строк, с 21 до 19 файлов.
- Удалены доменный TS-пример и неисправный find-polluter; приём изоляции тестов остался
  в условной справке. Помощники учитывают путь плана и незакоммиченные изменения.
- Восемь сценариев выбора инструкций проверены независимым агентом. 26/26 Node-проверок,
  валидация скилла, ссылки, локальная установка и регистрация ролей прошли.
- Исправлено понимание отдельных e2e-процессов: они относятся к работе тестировщика,
  не ко всем тестам разработчика и не к любой приёмке роли j-tester.
- Владелец одобрил публикацию редакции и обновление глобальных и проектных установок.
  После обновления пакета зарегистрированные роли устанавливаются повторно.
- Проверки этой редакции на реальном ZCode и native Unix не выполнялись.

Подробности: [document-routing](features/document-routing.md).

## Опубликованная исходная редакция

- Упаковка согласована владельцем; GitHub-репозиторий публичный.
- Исходники скилла и ролей перенесены без личной истории проектов.
- Проверки 16/16: установка ролей для трёх агентов, повторная установка, конфликты,
  резервные копии, некорректный ввод и отказ от записи через symlink.
- `npx skills` распознал один скилл и установил пакет для трёх агентов в изолированную
  папку с пробелами. Ресурсы и лицензии сохранены, метаданные Git не скопированы.
- Семь сгенерированных TOML прочитаны Python tomllib. Скилл прошёл quick_validate.
- Bash-помощники проверены в отдельном Git-проекте; права 100755 сохранены в индексе.
- Независимое ревью не нашло блокирующих дефектов.
- Публичный репозиторий: https://github.com/JumpAttacker/j-flow.
- Установка из GitHub через `npx skills add JumpAttacker/j-flow --skill j-flow -a zcode codex claude-code -y`
  прошла в отдельной папке; из установленного пакета зарегистрированы по семь ролей
  для каждого агента в изолированном профиле. Обновление через CLI также прошло.
- Установленные рабочие копии и роли в пользовательском профиле не изменялись.

## Ограничения

- Установка файлов не подтверждает полный рабочий прогон агента в каждой оболочке.
- Внешние скиллы и MCP подключаются отдельно; отсутствие инструментов должно быть явно сообщено.
