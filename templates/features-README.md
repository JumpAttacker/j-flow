# Фичи: как оно работает сейчас

Заметка заводится по факту: пришлось разбираться, как работает, или фичу только что сделали.
Через полгода описаны ровно те фичи, которые реально забываются.

## Указатель

|---|---|

## Правила

1. Указатели, а не копии: объяснение уже есть в коде, значит якорь `файл:строка`.
2. Якоря проверяются: `node <skill-root>/scripts/check-anchors.mjs <корень проекта>`.
3. Строка `Проверено на:` обновляется при каждой правке заметки.
