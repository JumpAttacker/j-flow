# Описание проекта: j-flow

Обновлено: 2026-10-05. Сверено с файлами пакета и его проверками.
База правки: `53df6cf`; описание относится к рабочей редакции обслуживания документов.

## Назначение и границы

Переносимый скилл полного цикла разработки конкретного проекта для Codex, Claude Code и ZCode.
Контроллер ведёт уточнение, согласование, исполнение, приёмку и постоянные документы проекта.
Задачи вне разработки и простые правки выполняются напрямую по применимым правилам.

## Основные потоки

Установка: CLI skills получает пакет → устанавливает скилл → отдельный установщик регистрирует роли.
Без регистрации контроллер передаёт тело роли общему агенту; без делегирования выполняет этапы сам.
Разработка: контекст и комплект документов → решение → одобрение → исполнение → приёмка → обслуживание документов.
Архитектурный путь: план → ревью плана → задачи SDD с ревью → итоговая проверка → приёмка.
Документация: при старте недостающее создаётся → источники собираются по задаче → хранитель обновляет карту,
state, заметки и проверки; незавершённый результат сохраняется с ограничениями.

## Данные и зависимости

Постоянные данные проекта: project, state, индекс фич и checks в `.j-flow/` по умолчанию.
Временные отчёты и доказательства размещаются в evidence, журнал SDD отдельно от постоянной карты.
Установщик, проверка якорей и помощники используют Node.js; Git CLI нужен для пакетов изменений
и автоматического каталога плана. Без Git процесс сохраняет журнал и версии файлов вручную.
Средства браузера, модели, частные MCP и команды продукта определяются доступной оболочкой и проектом.

## Ограничения

Наличие файлов и проверки установщика не подтверждают полный цикл разработки во всех клиентах.
Поведение агента проверяется отдельно; непроверенные результаты и доступность инструментов называются явно.
