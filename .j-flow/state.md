# Состояние j-flow

Обновлено: 2026-10-05

## Цель

Самодостаточное распространение через GitHub и `npx skills` для ZCode, Claude Code и Codex.

## Текущий прогон

- Упаковка согласована владельцем; GitHub-репозиторий публичный.
- Исходники скилла и ролей перенесены без личной истории проектов.
- Проверки 16/16: установка ролей для трёх агентов, повторная установка, конфликты,
  резервные копии, некорректный ввод и отказ от записи через symlink.
- `npx skills` распознал один скилл и установил пакет для трёх агентов в изолированную
  папку с пробелами. Ресурсы и лицензии сохранены, метаданные Git не скопированы.
- Семь сгенерированных TOML прочитаны Python tomllib. Скилл прошёл quick_validate.
- Bash-помощники проверены в отдельном Git-проекте; права 100755 сохранены в индексе.
- Независимое ревью не нашло блокирующих дефектов.
- Осталось опубликовать `JumpAttacker/j-flow` и проверить установку из GitHub.

## Ограничения

- Установка файлов не подтверждает полный рабочий прогон агента в каждой оболочке.
- Внешние скиллы и MCP подключаются отдельно; отсутствие инструментов должно быть явно сообщено.
