# Подтверждённые проверки пакета

Команды выполняются из корня j-flow. Проверяют пакет, не заменяют приёмку пользовательского продукта.

| Область | Проверка | Команда | Ожидаемый результат |
|---|---|---|---|
| Установщик, якоря, Node-помощники | Автоматизированные проверки поведения | `node --test scripts/*.test.mjs` | Нет провалов; пропуски явно названы |
| Изменения | Пробелы и конфликтные маркеры diff | `git diff --check` | Код 0 |
| Якоря карты и фич | Существование файлов и границы строк | `node scripts/check-anchors.mjs . --allow-empty` | Нет битых якорей; пустая проверка отмечена N/A |

Установка через skills и регистрация семи ролей каждого клиента проверяются в изолированной папке.
Валидация SKILL выполняется доступным валидатором skill-creator. Эти средства не являются зависимостями продукта.
