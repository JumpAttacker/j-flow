# Выполнить задачу

Исполнитель начинает с точного брифа, разрешённых файлов и обязательных интерфейсов.
Проверяет доступность входов; сообщает NEEDS_CONTEXT или BLOCKED, если задача не может
быть выполнена в указанных границах. Применяет общую политику SKILL.md и правила проекта.

Работу ведёт по существующим паттернам. Для бага сначала устанавливает причину;
значимое поведение получает воспроизводимую проверку. Тестовый процесс выбирается
по порученной работе, включая отдельные правила тестировщиков только в их области.
После изменения проверяются затронутые сценарии и читается собственный diff.

Отчёт содержит результат, файлы, команду/вывод проверки, открытые вопросы и очистку runtime.
Для хранителя перечисли изменения модулей, потоков, контрактов, данных, зависимостей
и рецептов работы с источниками; отсутствие таких изменений также отметь.
При исправлении дополняй предыдущий отчёт и список замечаний.
Коммит определяется разрешением, а не статусом DONE. Исполнитель не делегирует свою задачу.
